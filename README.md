# Tourism Management System

A complete Tourism Management System built using Java, Spring Boot, MySQL, HTML, CSS and JavaScript to manage tour packages, bookings, and customer details efficiently.

### 🛠️ Tech Stack
- **Backend:** Java, Spring Boot, Spring MVC, REST APIs
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Database:** MySQL
- **Tools:** Maven, Git, Postman

### ✨ Features
- User Registration & Authentication
- Browse and Search Tour Packages
- Tour Booking Management with CRUD Operations
- Admin Dashboard to Manage Packages, Users & Bookings
- Booking Confirmation & Customer Records
- Responsive UI for all devices

### ⚙️ How to Run Locally
1. Clone the repo
   git clone https://github.com/jenisha0303/tourism-management.git
2. Open in IntelliJ / Eclipse
3. Configure MySQL in application.properties
4. Run TourismManagementApplication.java
5. Open browser: http://localhost:8080
